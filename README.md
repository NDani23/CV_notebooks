## A collection of computer vision projects I worked on during my studies.

This repository contains several of my past works in the field of computer vision/machine learning.

Since these projects were developed for university courses, they are presented in Jupyter Notebook format so they can be easily tested and reviewed. For the same reason, every notebook in this repository has a "Open in Colab" button that allows you to quickly check out or even run the code snippets inside them.

There is an explanation or introduction at the top of each notebook about the objective and content of that project.

### Note
The projects presented here are small, educational solutions to show my interest and experience in the field of computer vision and machine learning.

2 of these projects were made as part of guided practicies, but the notebooks labeled with (homework) in the title were completely developed by myself.
